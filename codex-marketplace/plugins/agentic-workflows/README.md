# Agentic Workflows

This bundle projects the retained ECC workflow mechanics into a dedicated
topical home.

## Bundle contents
### ECC skills
- `agent-harness-construction`
- `autonomous-agent-harness`
- `continuous-agent-loop`
- `dynamic-workflow-mode`
- `dmux-workflows`
- `agentic-os`

### Documentation
- provenance and source mapping in `SOURCE.md`
- bundle inventory in `references/bundle-manifest.json`
- canonical source mapping in `references/source-map.md`

## Boundary
- The pack covers harness design, autonomous loops, dynamic workflow mode,
  and multi-agent dispatch.
- The pack does not absorb the evaluation, research, or security homes.

## Install shape

The installable skill zips are generated under
`generated/skill-zips/<skill-name>.zip` and can be
installed directly from those artifacts.
