# Frontend Pack

This plugin bundle projects retained Codex Cortex frontend application skills and
retained ECC frontend-oriented skills into an installable Codex marketplace
pack.

## Bundle contents

- Codex Cortex frontend skills:
  - `react-performance-optimization`
  - `accessibility-audit`
  - `ux-review`
  - `interaction-design`
  - `webapp-testing`
- ECC frontend-oriented skills:
  - `accessibility`
  - `angular-developer`
  - `browser-qa`
  - `design-system`
  - `e2e-testing`
  - `make-interfaces-feel-better`
  - `react-patterns`
  - `react-testing`
  - `swiftui-patterns`
  - `vue-patterns`
  - `windows-desktop-e2e`
- provenance and source mapping in `SOURCE.md`
- bundle inventory in `references/bundle-manifest.json`
- canonical source mapping in `references/source-map.md`

## Boundary

- `react-performance-optimization` carries React render, memoization, code splitting, virtualization, and profiling guidance.
- `accessibility-audit` carries WCAG 2.2 AA triage and keyboard, labels, contrast, and motion checks.
- `ux-review` carries heuristic UX review, accessibility review, and interaction analysis for frontend flows and components.
- `interaction-design` carries user flow, state transition, micro-interaction, and feedback pattern guidance.
- `webapp-testing` carries Playwright-based browser automation and local web application testing guidance.
- `accessibility` carries accessibility audit and remediation guidance from ECC custody.
- `angular-developer` carries Angular application development and best practices guidance.
- `browser-qa` carries browser-based QA and testing workflows.
- `design-system` carries design system architecture and component library guidance.
- `e2e-testing` carries end-to-end testing strategy and implementation guidance.
- `make-interfaces-feel-better` carries interface polish and micro-interaction refinement guidance.
- `react-patterns` carries React design patterns and architectural guidance.
- `react-testing` carries React-specific testing strategies and implementation guidance.
- `swiftui-patterns` carries SwiftUI design patterns and iOS frontend guidance.
- `vue-patterns` carries Vue.js design patterns and architectural guidance.
- `windows-desktop-e2e` carries Windows desktop application end-to-end testing guidance.
- The pack is sourced from retained `NickCrew/Claude-Cortex` frontend skills under the retained `claude-cortex` custody root and retained `affaan-m/ECC` frontend skills under the retained `ecc` custody root.
- The bundle is a projection over retained source custody, not a new source of truth.
