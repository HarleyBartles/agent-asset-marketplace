retained ECC language/framework skills into an installable Codex marketplace
pack.

## Boundary

- `typescript-advanced-patterns` carries TypeScript language and runtime guidance.
- `python-testing-patterns` carries Python testing idioms, fixtures, mocking, parametrization, property-based testing, and async test patterns.
- `async-python-patterns` carries Python async and concurrency guidance.
- `python-performance-optimization` carries Python profiling, algorithmic optimization, memory optimization, and acceleration guidance.
- `bun-runtime` carries Bun runtime patterns and guidance.
- `cpp-testing` carries C++ testing strategies and implementation guidance.
- `csharp-testing` carries C# testing strategies and implementation guidance.
- `dart-flutter-patterns` carries Dart and Flutter design patterns and architectural guidance.
- `django-celery` carries Django and Celery integration patterns.
- `django-patterns` carries Django framework patterns and best practices.
- `django-tdd` carries Django test-driven development workflows.
- `fastapi-patterns` carries FastAPI framework patterns and best practices.
- `flutter-dart-code-review` carries Flutter and Dart code review guidance.
- `fsharp-testing` carries F# testing strategies and implementation guidance.
- `golang-testing` carries Go testing strategies and implementation guidance.
- `kotlin-coroutines-flows` carries Kotlin coroutines and flows patterns.
- `kotlin-ktor-patterns` carries Ktor framework patterns and best practices.
- `kotlin-testing` carries Kotlin testing strategies and implementation guidance.
- `laravel-patterns` carries Laravel framework patterns and best practices.
- `laravel-plugin-discovery` carries Laravel plugin discovery and integration patterns.
- `laravel-tdd` carries Laravel test-driven development workflows.
- `nestjs-patterns` carries NestJS framework patterns and best practices.
- `perl-testing` carries Perl testing strategies and implementation guidance.
- `python-testing` carries Python testing strategies and implementation guidance from ECC custody.
- `pytorch-patterns` carries PyTorch deep learning patterns and best practices.
- `quarkus-patterns` carries Quarkus framework patterns and best practices.
- `quarkus-tdd` carries Quarkus test-driven development workflows.
- `rust-testing` carries Rust testing strategies and implementation guidance.
- `springboot-patterns` carries Spring Boot framework patterns and best practices.
- `springboot-tdd` carries Spring Boot test-driven development workflows.
- `swift-protocol-di-testing` carries Swift Protocol Dependency Injection testing guidance.
- `tinystruct-patterns` carries TinyStruct framework patterns and best practices.
- `tdd-workflow` carries general test-driven development workflow guidance.
- The pack is sourced from retained `NickCrew/Claude-Cortex` language/runtime skills under the retained `codex-cortex` custody root and retained `affaan-m/ECC` language/framework skills under the retained `ecc` custody root.
- The bundle does not own frontend, architecture, database, security, repo governance, CI, or generic engineering doctrine.
- The bundle is a projection over retained source custody, not a new source of truth.
