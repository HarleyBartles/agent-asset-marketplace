# Source

This plugin projects the first-party `dotnet` skill into a Codex marketplace pack.

## Boundary
- `dotnet` is first-party source custody under `codex-marketplace/plugins/dotnet-pack/skills/dotnet/`.

## Provenance

This plugin contains the first-party `dotnet` ecosystem skill in a Codex marketplace pack.

### Canonical source
- `dotnet` first-party skill: `codex-marketplace/plugins/dotnet-pack/skills/dotnet/`

### Pack shape
- Codex plugin root: `codex-marketplace/plugins/dotnet-pack/`
- Skill root: `codex-marketplace/plugins/dotnet-pack/skills/`
- Skills install from the Codex plugin root.
