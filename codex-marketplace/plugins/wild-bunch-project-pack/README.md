# Wild Bunch Project Pack

This plugin bundle is the first-party project-scoped marketplace surface for
`HarleyBartles/wild-bunch`.

## Bundle contents

- Wild Bunch project doctrine under `skills/wild-bunch-project-doctrine/`
- Wild Bunch domain modeling under `skills/wild-bunch-domain-modeling/`
- Wild Bunch .NET architecture guidance under `skills/wild-bunch-dotnet-architecture/`
- Wild Bunch browser-game guidance under `skills/wild-bunch-browser-game/`
- Wild Bunch verification guidance under `skills/wild-bunch-worker-verification/`
- source and provenance notes in `SOURCE.md`

## Provenance

- First-party Harley-authored project guidance
- Referenced marketplace assets and installability status are recorded in `SOURCE.md`

The copied skill docs stay in their own directories and are exposed through the
plugin manifest only after they exist locally.
