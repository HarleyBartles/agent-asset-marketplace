# Wild Bunch Project Pack

This plugin bundle is the self-contained project-scoped marketplace surface for
`HarleyBartles/wild-bunch`.

## Bundle contents

- first-party Wild Bunch project doctrine under
  `skills/wild-bunch-project-doctrine/`
- first-party Wild Bunch domain modeling under
  `skills/wild-bunch-domain-modeling/`
- first-party Wild Bunch .NET architecture guidance under
  `skills/wild-bunch-dotnet-architecture/`
- first-party Wild Bunch browser-game guidance under
  `skills/wild-bunch-browser-game/`
- first-party Wild Bunch verification guidance under
  `skills/wild-bunch-worker-verification/`
- copied marketplace skills for `game-studio`, `web-game-foundations`,
  `phaser-2d-game`, `game-ui-frontend`, `game-playtest`, `sprite-pipeline`,
  `agent-browser`, `aspnet-core`, and `linear-reference-architecture`
- source and provenance notes in `SOURCE.md`
- provenance map and supporting references in `references/`

## Provenance

- First-party Harley-authored project guidance
- Copied marketplace skills are documented in `references/provenance-map.md`

The copied skill docs stay in their own directories and are exposed through the
plugin manifest only after they exist locally. See
`references/provenance-map.md` for the first-party versus copied split.
