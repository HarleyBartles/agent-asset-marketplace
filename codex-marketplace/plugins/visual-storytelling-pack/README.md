# Visual Storytelling Pack

This bundle provides portable creative-direction and image-generation skills for
authored visual storytelling across images, pages, sequences, and interactive
worlds.

## Bundle contents

### Skills

- `directing-visual-stories` routes a story beat to deliberate composition,
  attention, framing, light, staging, rhythm, and medium-translation decisions.
- `generating-images` executes an approved raster-image direction through an
  authorised capability and reports truthful iteration and asset custody. It is
  a substantially modified Apache-2.0 derivative of OpenAI's bundled
  `imagegen`; see its `NOTICE.md` and retained source snapshot.

### Documentation
- provenance and source mapping in `SOURCE.md`
- bundle inventory in `references/bundle-manifest.json`

## Boundary
- The bundle stays focused on visual direction and raster-image generation; it
  does not absorb responsive implementation, accessibility procedure, game
  mechanics, or provider-specific execution adapters.
- `directing-visual-stories` is first-party synthesis. The derivative boundary
  and upstream attribution for `generating-images` remain explicit in the skill
  package.

## Install shape

Skills are installed from the Codex plugin roots under `codex-marketplace/plugins/<pack>/skills/<skill>/`.
