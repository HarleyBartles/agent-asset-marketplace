# Mcp Usage Pack

This bundle projects the first-party mcp-usage-pack skills.

## Bundle contents

### Documentation
- provenance and source mapping in `SOURCE.md`
- bundle inventory in `references/bundle-manifest.json`

## Boundary
- The first-party mcp-usage-pack skills stay bundled together as a focused MCP-usage set.
- The bundle stays first-party only and does not absorb unrelated workflow packs.

## Install shape

Skills are installed from the Codex plugin roots under `codex-marketplace/plugins/<pack>/skills/<skill>/`.
