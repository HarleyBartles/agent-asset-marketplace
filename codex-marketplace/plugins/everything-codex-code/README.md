# Everything Codex Code

This plugin bundle projects the selected ECC Superpowers-style workflow skills
into a generated aggregate installable Codex marketplace pack.

The plugin shell is Harley-authored and MIT licensed. Projected skill roots
retain their upstream authorship and license evidence in the bundle manifest,
source map, and retained third-party snapshot. The selected skills are mirrored
from the existing `superpowers-ecc` marketplace projection rather than copied
directly from the upstream ECC repository.

## Boundary

- `agent-harness-construction` owns agent action-space and tool-format design.
- `ai-first-engineering` owns the operating model for AI-heavy implementation.
- `deployment-patterns` owns deployment, CI/CD, rollback, and readiness patterns.
- `dmux-workflows` owns multi-agent orchestration across harnesses.
- `messages-ops` owns evidence-first live messaging workflows.
- `ml-adoption-playbook` owns the AI/ML adoption framing slice.
- `prediction-market-oracle-research` owns prediction-market source research.
- `recursive-decision-ledger` owns recursive decision and evidence-trail workflows.
- `research-ops` owns current-state research and recommendation workflows.
- `safety-guard` owns destructive-operation prevention and autonomy guardrails.
- `search-first` owns research-before-coding behavior.
- `team-agent-orchestration` owns team-based orchestration and handoffs.
- `team-builder` owns interactive team composition.
- `token-budget-advisor` owns token-budget guidance.
- The bundle stays out of branding, social publishing, media production, and
  unrelated domain-specialist skills unless another issue explicitly composes
  them in.
- The bundle is a generated aggregate projection over the selected ECC
  workflow skills already installed in `superpowers-ecc`, not a new source of
  truth and not a raw mirror of upstream ECC custody.
