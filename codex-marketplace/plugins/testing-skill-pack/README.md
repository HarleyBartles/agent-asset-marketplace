# Testing Skill Pack

This plugin package exposes the upstream standalone Replit skill family as a
Codex marketplace asset.

## Contents

- 28 imported skills under `skills/`
- provenance and source mapping in `SOURCE.md`
- bundle inventory in `references/bundle-manifest.json`

through the plugin manifest only after they exist locally.
