# Superpowers Mega Pack

This bundle projects the retained third-party Superpowers workflow skills verbatim.

## Bundle contents
- The mega pack contains the pure third-party Superpowers skills selected from the retained upstream snapshot.
- First-party helper skills and adapter-backed variants stay in `superpowers-plus`.

## Documentation
- provenance and source mapping in `SOURCE.md`
- bundle inventory in `references/bundle-manifest.json`

## Boundary
- The mega pack is third-party verbatim only.
- Adapted Superpowers projections are intentionally excluded from this root.

## Install shape

The installable skill zips are generated under `generated/skill-zips/superpowers-mega-pack/<skill-name>/skill.zip` and can be installed directly from those artifacts.
