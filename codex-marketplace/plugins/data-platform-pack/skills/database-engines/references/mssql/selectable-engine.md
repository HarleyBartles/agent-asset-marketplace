# MS-SQL selectable engine guidance

Use this reference only when the user explicitly selects Microsoft SQL Server.
It covers T-SQL differences, SQL Server Management Studio and Azure Data Studio
tooling, and Windows or Azure deployment notes that differ from PostgreSQL and
SQLite.

This guidance is first-party synthesis supported by the proprietary Microsoft
SQL Server documentation citation. It is not vendored source. Keep the guidance
bounded to selectable differences and common pitfalls, not exhaustive feature
coverage.
