# Security Scan Pack

Clean-room marketplace pack for security scan orchestration, threat modeling,
candidate discovery, validation receipts, attack-path analysis, and final
markdown reporting.

This pack is intentionally not a copy of the proprietary
`openai/plugins/plugins/codex-security` root. It is authored from first
principles and stays within repo-owned governance plus permissively licensed
scanner references.

## Coverage

- repository and scoped-path scan orchestration
- threat model capture before scanning
- secret, dependency, container, and IaC scan integration
- candidate finding discovery and deterministic receipts
- attack-path and severity analysis
- final markdown report assembly
