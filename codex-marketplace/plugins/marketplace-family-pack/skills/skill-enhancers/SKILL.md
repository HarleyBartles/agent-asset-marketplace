# Skill Enhancers

Use this skill as the control plane for skill creation and maintenance work.

## What it preserves

- skill creation discipline
- validation before packaging
- zero-tech-debt repair loops
- targeted utility over broad generic instruction

## When to use

- You are drafting or revising a skill package.
- You need a validation pass before a skill is exposed in the marketplace.
- You want to keep meta-work narrow and testable.

## Source anchors

- Upstream family root: `plugins/skill-enhancers`
- Representative upstream assets: `skill-creator`, `validate-plugin`, `zero-tech-debt`

## Market output

This skill is the repo-held, installable version of the upstream family
consequence for skill tooling and maintenance.
