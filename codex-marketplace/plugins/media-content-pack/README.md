# Media Content Pack

This plugin bundle projects retained ECC media/content skills into an installable Codex marketplace pack.

## Bundle contents

- ECC media/content skills:
  - `competitive-report-structure`
  - `fal-ai-media`
  - `frontend-slides`
  - `manim-video`
  - `nutrient-document-processing`
  - `remotion-video-creation`
  - `seo`
  - `visa-doc-translate`
  - `video-editing`
  - `videodb`
- provenance and source mapping in `SOURCE.md`
- bundle inventory in `references/bundle-manifest.json`
- canonical source mapping in `references/source-map.md`

## Boundary

- `competitive-report-structure` carries competitive report structure patterns.
- `fal-ai-media` carries Fal.ai media operations patterns and guidance.
- `frontend-slides` carries frontend slide creation patterns.
- `manim-video` carries Manim video creation patterns.
- `nutrient-document-processing` carries nutrient document processing patterns.
- `remotion-video-creation` carries Remotion video creation patterns.
- `seo` carries SEO optimization patterns and best practices.
- `visa-doc-translate` carries Visa document translation patterns.
- `video-editing` carries video editing patterns.
- `videodb` carries VideoDB patterns.
- The pack is sourced from retained `affaan-m/ECC` media/content skills under the retained `ecc` custody root.
- The bundle does not own language patterns, frontend, architecture, security, repo governance, CI, or generic engineering doctrine.
- The bundle is a projection over retained source custody, not a new source of truth.
