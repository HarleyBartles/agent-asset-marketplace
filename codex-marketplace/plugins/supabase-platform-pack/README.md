# Supabase Platform Pack

> 30 production-grade Claude Code skills for Supabase, wrapped as a Codex
> marketplace plugin with source provenance and license evidence.

## What This Bundle Is

This pack exposes the upstream standalone Supabase skill database as a
market-consumable Codex plugin. The upstream docs are preserved under
`skills/` and the import ledger lives in
`references/bundle-manifest.json`.

## Coverage

- Authentication, database, storage, realtime, and edge-function workflows
- CI/CD, deployment, observability, reliability, and performance tuning
- Production hardening, incident response, and enterprise access control

## Source

- Upstream repo: `jeremylongshore/claude-code-plugins-plus-skills`
- Pinned commit: `e773501f1dfb409fc71fccdaf6ac2898fedf66d6`
- Source root: `plugins/saas-packs/skill-databases/supabase/`

## Installation

Install this plugin from the local marketplace surface in this repository.
All skill docs are available under `skills/<skill-id>/SKILL.md`.

## Notes

The upstream Supabase bundle is MIT-licensed. This wrapper preserves the
original skill boundaries and adds the marketplace metadata needed for Codex.
