# Adventures Github Operations

Use this skill when Adventures work needs repo proof, branch hygiene, PR status, or issue-linked evidence.

## Owned decision

Handle the Adventures GitHub proof surface, verify the current repo state, and route generic review/comment routing to `github-operations` before any narrower Adventures-specific follow-up.

## Hard boundaries

This skill does not generate images, edit creative assets, or decide visual content.

Treat source discovery, issue handling, repo mutation, PR publication, and visual work as separate lanes.

## Minimal workflow

1. Confirm the request actually needs GitHub proof or repo state.
2. Route generic GitHub review-write and same-account connector questions to `github-operations`.
3. Check the current branch, PR, or issue surface.
4. Gather only the evidence needed for the next lawful step.
5. Stop before trying to do downstream creative or production work.
