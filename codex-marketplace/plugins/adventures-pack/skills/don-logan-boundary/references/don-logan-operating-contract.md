# Don Logan operating contract

Use this reference for full Don Logan preconditions, non-triggers, nudge/follow-up shape, pressure ladder, and output posture.

## Core lesson

Don Logan is not stronger wording. It is a control-plane boundary for execution drift after authority is settled.

The failure mode is not ambiguity. The failure mode is a worker spending finite execution budget on process instead of completing a known lawful task: re-preflighting known context, writing reports about what should be done, arguing against the task without a real blocker, or returning a plan instead of the authorized result.

The correction exists because more explanation can feed that loop. The useful steer is: the task is known; execute it or return the concrete blocker that prevents execution.

## Preconditions

Use this skill only when all of these are true:

- the task is already authorized;
- the lawful actor or worker route is known;
- scope, constraints, protected surfaces, and success condition are known;
- the worker is live or has just returned on the same task;
- the worker is materially drifting into process, justification, or non-execution;
- a bounded nudge or same-task follow-up can preserve the original task and return contract.

If any precondition is missing, do not use Don Logan. Repair the dispatch, clarify the blocker, or route through the proper skill.

## Non-triggers

Do not use Don Logan for:

- ordinary urgency or frustration;
- GPT's under-specified dispatch;
- missing actor route, source route, doctrine, or authority;
- genuine ambiguity or invariant conflict;
- a real blocker reported by the worker;
- ordinary exploration that remains inside the task;
- post-hoc verification doubt;
- adding new related work after the original task is complete.

A bad original dispatch that will predictably need Don Logan later should fail the current dispatch gate instead of relying on a future correction.

## Nudge and follow-up shape

A Don Logan nudge is an addendum to live work. It must not restate, replace, broaden, or weaken the original dispatch.

A Don Logan follow-up is same-task continuation after an evasion-shaped return. It must have its own return contract for what the worker must return next.

Both remain dispatch-family artifacts and must pass the current dispatch gate before printing.

## Pressure ladder

Increase pressure only when repeated evasion is observed. Never pressure past a real blocker, protected surface, or authority limit.

- First correction: stop substituting process for execution. Complete the known task or return the concrete blocker.
- Second correction: repeated evasion is now the issue. Do not re-preflight, re-argue, or return another plan. Execute the authorized task or return the specific blocker.
- Final correction: complete and publish the authorized work if lawful, or return BLOCKED with the concrete lawful blocker. More process text is non-compliant.

## Output posture

Do not show a Don Logan receipt. If the boundary is triggered and passes the current dispatch gate, print the bounded nudge or follow-up only.

If the boundary does not trigger, explain the safer route: wait for the worker, issue an ordinary nudge, prepare a follow-up, repair the dispatch, or block.
