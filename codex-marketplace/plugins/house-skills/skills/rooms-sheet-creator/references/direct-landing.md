# Direct landing

GPT direct landing is allowed only where a repo-resident governance surface has established a narrow lane.

## Prompt lane

Participant prompt sheets are a governed GPT direct-landing lane in `rooms-world` Research.

Allowed surfaces:

- `Research/source_materials/participant_accounts/**` for prompt sheets and prompt-sheet-local notes.
- `Research/Participant Prompt Sheets/INDEX.md` for navigation.

## Peek lane

Participant sneak peeks are a governed GPT direct-landing lane in `rooms-world` Research.

Allowed surfaces:

- `Research/Participant Sneak Peeks/**` for participant-facing sneak peek scaffolds.
- `Research/Participant Sneak Peeks/INDEX.md` and minimal lane navigation.

## Recall lane

Do not persist recall sheets by default until a governed repo-resident recall lane exists or Harley explicitly approves
the exact write surface in the current conversation. Drafting recall sheets in chat is allowed.

## Forbidden surfaces

The direct-landing exceptions do not authorize:

- canon execution or Brian canon persistence;
- Pit/archive extraction or mutation;
- transcript mutation;
- ProjectDB mutation;
- manuscript drafting;
- character investigation persistence;
- general repo mutation;
- edits outside the narrow lane and minimal navigation.
