# PostgreSQL connection and drivers

Use this reference when an application needs to connect to PostgreSQL or when
you need to choose a driver, configure a connection string, or use the psql
command-line client. PostgreSQL supports many client libraries; choose the one
that matches the host language and the required protocol features.

The authority for this guidance is the PostgreSQL 18.4 Server Administration and
Client Interfaces chapters. Operational prose adapts those sections into
task-oriented guidance. Do not copy large tables of configuration parameters;
instead, state the most common values and point the user to the vendored docs
for the full list.
