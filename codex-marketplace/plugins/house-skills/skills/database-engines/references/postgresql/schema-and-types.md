# PostgreSQL schema and data types

Use this reference when designing a PostgreSQL schema, choosing data types, or
writing data-definition statements. PostgreSQL extends standard SQL with rich
type support, arrays, JSONB, and custom domains; choose the simplest type that
preserves the required semantics.

The authority is the PostgreSQL 18.4 SQL Language sections on data definition
and data types. Adapt the definitions into guidance on when to use each type
and how to declare constraints. Do not reproduce the full type matrix; summarize
the decisions the user must make.
