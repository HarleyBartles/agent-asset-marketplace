# Artifact verification gate

Zoom Outs Buster is not fully green until the model is tested against source material.

## Source material role

Artifacts are the regeneration test surface. They are not optional support or decorative examples.

Ask: does the actual persisted material behave like this?

## Required distinction

- `green_model_only`: plausible, useful in conversation, not yet persistence-ready.
- `amber_artifact_needed`: likely needs source inspection before use.
- `green_artifact_verified`: checked against relevant artifacts and still regenerates behaviour.

## Candidate source surfaces

Use the smallest sufficient set:

- character voice files
- room behaviour/system docs
- sketches, tweets, threads, transcripts, or manuscript excerpts
- World canon/system surfaces
- Pit/archive evidence only when lawful and needed
- reports only as reports

## Persistence route

A verified model may become a persistence candidate, but must still pass source partitioning, canon pressure, ambiguity,
invariant, and dispatch gates before repo mutation.
