# Lane Checks

PIG-returned candidates are still candidates. A PIG self-QA pass is useful production evidence, but it does not replace this external lane review when Harley asks for Adventures QA, deck readiness, asset readiness, canon lock, or acceptance.

Use this reference when a candidate needs detailed lane review.

## Preproduction reference

A preproduction reference is accepted only when it can guide later image generation without contaminating canon. It must
match its intended lane, preserve class identity, and avoid overstuffed poster composition.

## Patch scene

A Patch scene is accepted only when Patch is canonical, singular, active, and mapped to the slide or story beat. Other
people, agents, terminals, and systems must not look like Patch.

## Anti-pattern reference

An anti-pattern reference may show rejected visuals only when the image makes the rejection clear. It must not be usable
as ordinary canon by mistake.
