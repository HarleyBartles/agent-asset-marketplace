# OpenAI Developer Pack

Clean-room marketplace pack for OpenAI developer workflows.

It is intentionally not a copy of the proprietary `openai/plugins/plugins/openai-developers` root. The pack is written from first principles and aligned with official OpenAI docs and permissive SDK references.

## Coverage

- OpenAI API app development
- Agents SDK workflows in Python
- Agents SDK workflows in TypeScript
- ChatGPT Apps SDK planning and scaffolding
- MCP server and app integration guidance
- Evals and troubleshooting guidance
- Safe local environment variable setup
