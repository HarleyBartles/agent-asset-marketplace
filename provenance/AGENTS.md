# AGENTS.md

Scope: `provenance/`

This scope covers provenance notes, activity logs, trust records, and custody
evidence.

Defer to the repository root `AGENTS.md` for global doctrine, publication
rules, and upstream-drain policy.

## Review guidelines

- Flag provenance claims that do not match the actual repository paths or
  source roots of the mirrored or adapted assets.
- Flag license or attribution drift as soon as the evidence no longer supports
  the stated source history.
- Flag activity-log or ledger records that no longer explain the current
  marketplace surface or registry state.
- Flag provenance prose that implies repo completion without a corresponding
  marketplace asset, manifest, or validation hook.
