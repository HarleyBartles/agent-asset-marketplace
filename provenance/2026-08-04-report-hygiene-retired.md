# Report-hygiene reference retired from `base-doctrine`

## What changed

The `report-hygiene` reference was originally a `base-doctrine/references/report-hygiene.md` document. It has been moved into the `writing-with-clarity` skill as `references/report-hygiene-checklist.md` because the content is primarily about drafting and reviewing prose intended for human readers — reports, verification summaries, worker returns, and publication notes.

## Rationale

- `base-doctrine` should guard cross-project control-plane truths and failure modes.
- The mechanics of clear, honest, partitioned reporting belong with the writing quality skill.
- `writing-with-clarity` is already invoked for reports, README files, and human-facing summaries.

## New canonical location

`sources/first_party/skills/writing-with-clarity/references/report-hygiene-checklist.md`

## Updated routing

- `base-doctrine/SKILL.md` now routes report-like-surface work to `writing-with-clarity/references/report-hygiene-checklist.md`.
- `writing-with-clarity/SKILL.md` lists the new reference in its `Reference routes` table.
