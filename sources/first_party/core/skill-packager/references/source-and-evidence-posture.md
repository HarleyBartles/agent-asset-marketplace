# Source and evidence posture

Load this reference only when packaging work depends on repository evidence, connector availability, source-route claims, external package evidence, or a failed source route. Do not load it for ordinary packaging when all source files are already staged locally and the task is just to validate and package them.

For ordinary skill packaging, prefer local package inspection and the bundled validation scripts. Source-route work is unnecessary when the complete staged skill folder is already present and no repository claim is being made.
