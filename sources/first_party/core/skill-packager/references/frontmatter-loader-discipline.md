# Frontmatter Loader Discipline

Use this reference when packaging existing-skill updates, repairing loader failures, or preparing a batch of installable skill zips.

Keep frontmatter loader-safe and discovery-useful. The `description` field is the metadata discovery contract for trigger routing, not a place for doctrine, long workflows, detailed edge cases, or queue contracts.

Description quality is governed by cognitive load and routing usefulness, not by an arbitrary character-count ceiling. Do not truncate, wrap, or otherwise alter a fit-for-purpose description merely because it exceeds a local style threshold.
