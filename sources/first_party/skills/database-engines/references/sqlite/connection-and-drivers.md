# SQLite connection and drivers

Use this reference when connecting to SQLite from an application or script.
SQLite is an embedded engine; most connections use a language binding or the
sqlite3 command-line shell.

The authority is the SQLite 3.53.3 documentation on the C API and language
bindings. Adapt the connection guidance into language-neutral rules. Note that
SQLite URI filenames and mode flags are common sources of confusion.
