# Operational guidance

Use this reference when the database-engines skill is asked to route between
PostgreSQL, SQLite, and MS-SQL, or when a concept such as connection management
or transactions applies to more than one engine. Start by asking which engine
the user is using; if they do not know, default to the shared guidance and then
ask clarifying questions.

The shared concepts here are first-party synthesis. They are not a verbatim copy
of any one vendor manual. Use the engine-specific references for driver names,
syntax, and tooling details. Keep MS-SQL guidance behind an explicit user
selection because the skill does not vend Microsoft documentation.
