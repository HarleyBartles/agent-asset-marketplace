# PostgreSQL backup and replication

Use this reference when backing up, restoring, or replicating PostgreSQL. Choose
the tool that matches the recovery-point objective and the operational
environment.

The authority is the PostgreSQL 18.4 Server Administration chapters on backup
and restore and on high availability, load balancing, and replication. Adapt
the tool descriptions into decision guidance. Do not reproduce full pg_dump
option lists; point to the vendored docs for exhaustive options.
