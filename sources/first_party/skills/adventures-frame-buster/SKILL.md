# Adventures Frame Buster

Use this skill as the canonical frame-readiness router for Adventures work.

## Owned decision

Decide whether the frame family is ready, needs repair, or should route to a more specific visual skill.

## Hard boundaries

This is deterministic readiness work.

It does not generate or edit images.

## Minimal workflow

1. Identify the seed or frame proposal.
2. Check the source basis and requested lane.
3. Aggregate the readiness result.
4. Stop before production work.
