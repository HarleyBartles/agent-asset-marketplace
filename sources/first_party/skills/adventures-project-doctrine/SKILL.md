# Adventures Project Doctrine

Use this skill when an Adventures request needs the shared project posture before a more specific skill.

## Owned decision

Choose the lawful Adventures lane before another tool, connector, repo mutation, or downstream production route is selected.

## Hard boundaries

Deterministic planning, source discovery, QA, image readiness, generation/editing, asset-sheet compilation, deck/package work, and acceptance are separate lanes.

QA does not authorize another image call.

Do not treat bundle mirrors as the source of truth. They project canonical House Skills sources.

## Minimal workflow

1. Confirm the request is active Adventures project work or a project handoff.
2. Identify the smallest sufficient lane.
3. Keep planning, discovery, QA, generation/editing, compilation, and acceptance separate.
4. Stop before downstream mutation from doctrine alone.
