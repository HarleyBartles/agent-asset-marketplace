# Architecture Decision Records

This directory records architecture decisions that continue to constrain the
repository. It is not an implementation-plan archive and it is not agent
doctrine.

Records are numbered in decision order. A record states the current decision,
its context, consequences, and the durable source that now owns its operation.
Git history, not this log, records execution details.
