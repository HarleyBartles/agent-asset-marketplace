# MARK-266 Implementation Record

**Goal:** create `everything-codex-code` as an installable aggregate marketplace projection of the ECC workflow skills already selected into `superpowers-ecc`.

## Scope

- Added a new marketplace plugin root at `codex-marketplace/plugins/everything-codex-code/`.
- Mirrored the selected ECC workflow skills from the existing `superpowers-ecc` projection into the new aggregate root.
- Added a new bundle manifest, source map, provenance note, and plugin metadata that make the installable projection posture explicit.
- Updated the marketplace root inventory, marketplace manifests, repo index, and registry outputs so the new root is installable.
- Added validator coverage and a regression test for the new projection shape, with the selected set derived from the bundle manifest and source map.
- Regenerated the skill-zip artifacts for the new pack through the normal tooling path.
