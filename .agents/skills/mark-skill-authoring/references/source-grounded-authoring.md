# Source-grounded authoring

Use `superpowers-plus:writing-skills` when creating, reviewing, or refreshing a skill. Start with the scaffolder, then keep the skill's operational guidance in `SKILL.md` and `references/`.

Use no inline citations in operational skill text by default. Put authority metadata, citations, derivation boundaries, and review evidence in `assets/authority/`.

Freshness is manual: a human must review the authority, record retrieval details, and approve any refresh before the skill changes.
