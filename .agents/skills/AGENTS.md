# Installed Skills Guidance

This directory is a repo-local projection surface. It is not canonical source.
For repo-wide doctrine, compose with the root [AGENTS.md](../../AGENTS.md).

How to use these skills:

- Start with `work-mode-router` to classify the durable route from Linear and
  repo evidence.
- Use `repo-worker-base` for fresh-main, worktree, branch, PR, validation, and
  publication hygiene.
- Use `linear-issue-shaping` for Linear packet shaping and worker-readiness
  handling after route classification.
- Use `boring-loop` to keep the next move small and falsifiable.
- Use `connector-safety` for any blocked or sensitive connector write.
- Use `github-operations` only after a GitHub artifact exists.
- Use `unslop-plus` and `safe-large-file-writing` as support skills when the
  workflow needs anti-slop or safer large text writes.

Update rules:

- Treat the skill source paths listed in [INDEX.md](INDEX.md) as the source of
  record for the projected local folders.
- When the matching vendored market skill changes, update the canonical source
  custody first, then reproject this folder from that source, then refresh the
  index.
- Do not hand-edit the projected folders when the source custody is available.
- If the local projection and the source custody diverge, treat that as drift
  and repair the projection from source.

Boundary:

- This folder supports repo workers.
- It does not replace `/using-superpowers`.
- It does not replace the canonical source skill custody under `sources/`.

For the durable marketplace execution model, read [Marketplace worker doctrine](../docs/marketplace-worker-doctrine.md) and compose it with the root [AGENTS.md](../../AGENTS.md).
