# CI validation pipeline

Every repo that uses `repo-standards` should have a `scripts/ci-preflight` script
that mirrors the CI checks for that repo. The script defaults to applying the
repo-wide `INDEX.md` mesh and other preflight checks, supports a read-only
`--check` mode, and prints the exact command to run when a check fails. The
`.git/hooks/pre-commit` hook runs the preflight script, and CI runs the same
checks as separate workflow steps.

## Preflight: `scripts/ci-preflight.sh` / `scripts/ci-preflight.ps1`

A repo-owned script that composes the same checks CI runs. By default it applies
changes (for example, regenerating the agent mesh). Pass `--check` to validate
without writing. The `repo-standards` template for this file is a commented menu
of available checks; each repo edits it to list the checks its CI uses.

## Pre-commit hook: `.git/hooks/pre-commit`

The hook is generated by `repo-standards` and executes `scripts/ci-preflight.sh --check`
for every commit. If the preflight fails, the commit is blocked. This ensures
each pushed commit has passed the local checks. Do not bypass the hook with
`--no-verify`.

## CI workflow

CI composes the same checks as separate workflow steps. Each step has its own
label so failures are easy to attribute. CI does not call the preflight script;
it runs the same commands directly.

## What to do when a check fails

Every check in `scripts/ci-preflight` must print the repair command to stderr
before exiting. For example:

- lint -> `python -m ruff check --fix <files> && python -m ruff format <files>`
- repo shape -> `python .agents/skills/repo-standards/scripts/repo_standards.py --apply --yes`
- agent mesh -> `python .agents/skills/generating-agent-mesh/scripts/generate_index_mesh.py`
- marketplace drift -> `python tools/rebuild_marketplace.py`

Run the repair command, then re-run `scripts/ci-preflight.sh --check`.

## Template menu

The `repo-standards` `ci-preflight` template ships with these commands available.
A repo copies the ones it needs into its `scripts/ci-preflight`:

- `bash .agents/skills/repo-standards/scripts/repo-standards.sh --check`
- `bash .agents/skills/repo-standards/scripts/scaffold-all.sh --check`
- `bash .agents/skills/generating-agent-mesh/scripts/generate-index-mesh.sh --check`
- `bash .agents/skills/generating-agent-mesh/scripts/validate-agent-mesh.sh --check`
- `bash .agents/skills/refreshing-installed-skills/scripts/refresh-installed-skills.sh --check`
- repo-specific lint command
- repo-specific final CI command, e.g.
  `python tools/rebuild_marketplace.py --phase <inventory|heal|project|index|catalog|validate> --check`
