# Plan 2: Immutable Snapshot Epochs and Authority Manifest Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `executing-plans` (recommended - tasks are sequential) or `subagent-driven-development` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make `freeze-review-input` and `refresh-review-input` real: live repository/PR acquisition bound to full base/head/tree/diff/metadata identity, a sealed authority-discovery policy producing a transcript-witnessed authority manifest, a sealed provider feedback-history policy producing immutable feedback findings, and epoch-advancing drift refresh - all on the hash-chained witness substrate this plan ships.

**Architecture:** A new witness substrate (`review_core/witness_log.py`) ingests session transcript records into a sha256-chained append-only log and backs a live `TranscriptWitnessVerifier`. A hooks pack (`assets/hooks/` + `hooks.v1.json` template) makes enumeration sessions emit harness records. A sealed `AuthorityDiscoveryPolicy` + `FeedbackHistoryPolicy` drive `review_core/acquisition.py`'s live `AuthorityDiscoverySource`, which the engine already calls via `acquire(action, current_snapshot)`. The freeze/refresh payload grammar gains a `findings` key for feedback-sourced findings. `reviewctl` gains an `enumerate` verb (the transcript-witnessed tool call) and a `--acquired` flag on `complete`; `doctor` gains the per-row live rechecks Plan 1 deferred.

**Tech Stack:** Python 3 (stdlib only, matching `review_core` conventions), `git`/`gh` CLIs for acquisition, Devin hooks for transcript emission, pytest for tests.

**Spec:** `.agents/specs/2026-09-12-iterative-review-calibrated-green-design.md` (normative green/snapshot/witness contract) and `.agents/specs/2026-08-21-trustworthy-iterative-review-design.md` (authority-manifest payload, sealed policy semantics, feedback lifecycle at lines 196-206).

## Global Constraints

- Runtime gate: all live acquisition paths require Devin Desktop runtime detection; on any other runtime the composition root stays fail-closed and every v2 action reports `inert`. Do not weaken `engine.runtime_supported`.
- Source custody: canonical edits land in `codex-marketplace/plugins/superpowers-plus/skills/iterative-review/`; `.agents/skills/iterative-review/` is regenerated by `py -3 tools/run.py installed-skills --apply`, never hand-edited.
- Effective policies (`authority-discovery`, `feedback-history`, witness) resolve from shipped defaults or the reviewed repository's **base revision**, never the reviewed head. Candidate edits to policy are review subjects only.
- Witness records are derived from the transcript/witness store, never caller-authored. `source_locator` values resolve only through the sealed `WitnessPolicy` namespaces.
- Feedback findings are immutable: provider-side Resolve is observation evidence only; a `feedback`-sourced finding closes only through the normal adjudication lifecycle. Re-enumeration never deletes or resurrects a finding with lawful closure.
- `pr_metadata_sha256` covers a **content-bearing projection only**: title, body, labels, assignees, milestone, and explicitly linked issues. Lifecycle fields (`isDraft`, `state`, review-decision counters) are excluded so draft/ready transitions do not force epoch refresh.
- Snapshot acquisition blocks (never proceeds with degraded identity) on: ambiguous base (no unique merge-base), shallow history, uncommitted review input (worktree content differs from `head_sha`), non-remote head, missing/unauthenticated `gh` connector, and unavailable required authority.
- `refresh-review-input` requires the payload `drift_reasons` list to name every changed `SNAPSHOT_SUBJECT_FIELDS` member plus `feedback_history`/`unresolved_feedback` deltas; byte-identical subjects stay refused by the existing `no-drift` rule.
- Epoch binding stays fail-closed: every record this plan installs (authorities, findings, manifest, witnesses, evidence) carries `snapshot_epoch`/`snapshot_fingerprint` of the snapshot being installed.
- No placeholders: every interface name, file path, and test name in this plan is the contract executors use.
- Verification: focused tests via `py -3 -m pytest <test-file> -x -q` run **from the worktree root**; the canonical gate is the tracked pre-commit hook (`ci --apply` + `ci --check --diagnostics`), never `--no-verify`.

```python
WITNESS_LOG_SCHEMA_VERSION = 1

class WitnessLog:
    """sha256-chained append-only JSONL witness store at `path`.

    Entry shape (canonical JSON, one object per line):
      {"schema_version": 1, "seq": int, "recorded_at": iso8601,
       "session_id": str, "tool_use_id": str|None,
       "record_kind": str,            # "PreToolUse"|"PostToolUse"|"marker"
       "payload_sha256": sha256,      # hash of the verbatim hook record bytes
       "payload": dict,               # verbatim hook record
       "prev_sha256": sha256,         # entry_sha256 of seq-1, or 64 zeros
       "entry_sha256": sha256}        # hash of this entry minus entry_sha256
    """

    def __init__(self, path: Path) -> None: ...
        # Creates parent dir 0700 and file 0600 when absent. Refuses to open
        # a world/group-writable existing file (permission drift = tamper signal).

    def append(self, *, session_id: str, tool_use_id: str | None,
               record_kind: str, payload: dict) -> int: ...
        # Returns the entry seq. Rejects non-dict payload, empty session_id,
        # record_kind outside the three allowed values.

    def verify_chain(self) -> tuple[bool, str | None]: ...
        # Recomputes every entry_sha256 and prev link. Returns (True, None)
        # or (False, "tamper at seq N"|"gap at seq N"|"malformed line N").

    def entries(self) -> list[dict]: ...
    def chain_head(self) -> str: ...  # entry_sha256 of last entry or 64 zeros


def ingest_transcript_segment(
    log: WitnessLog,
    *,
    transcript_path: Path,
    session_id: str,
    tool_use_id: str,
    marker: str,
) -> tuple[list[int], str, dict]:
    """Append the transcript records witnessing one tool call.

    Reads `transcript_path` (session-keyed JSONL hook transcript), selects the
    Pre/Post records whose `tool_use_id` equals `tool_use_id` and whose
    `session_id` equals `session_id`, requires the marker string to appear in
    the Post tool_response bytes, appends them to `log`, and returns
    `(record_positions, chain_head_at_record, transcript_range)` where
    `transcript_range` is::

        {"session_id": session_id,
         "transcript_sha256": sha256 of the selected records' canonical-JSON
                              serializations concatenated in transcript order,
         "first_record": int, "last_record": int}

    Fails closed (raises `WitnessVerificationError("missing-source", ...)`)
    when the records are absent, out of order, or the marker is missing.
    """


class TranscriptWitnessPolicy:
    """WitnessPolicy admitting hook-transcript locators for local kinds and
    github-remote locators for remote kinds."""

    def __init__(self, *, transcript_root: Path, witness_root: Path) -> None: ...
    @property
    def sha256(self) -> str: ...
        # sha256 over canonical JSON:
        # {"policy_id": "review-core-transcript-witness", "version": "1",
        #  "transcript_root_sha256": sha256(str(transcript_root).encode()),
        #  "witness_root_sha256": sha256(str(witness_root).encode())}
    @property
    def sources(self) -> tuple: ...
    def permits(self, *, kind: str, source: str, locator: str) -> bool: ...
        # local kinds: source == "hook-transcript" and locator resolves under
        # witness_root (after path canonicalization, no traversal).
        # remote kinds: source == "github-remote" and locator matches
        # r"^github://[A-Za-z0-9_.-]+/[A-Za-z0-9_.-]+/" (namespace only; live
        # remote re-fetch verification is a later plan).
        # unknown kinds never permitted.


class TranscriptWitnessVerifier:
    """Real WitnessVerifier bound to a review's witness log root."""

    def __init__(self, policy_obj: TranscriptWitnessPolicy, *,
                 witness_root: Path, review_id: str) -> None: ...
    @property
    def policy(self) -> TranscriptWitnessPolicy: ...
    def verify(self, *, stored_record_bytes, expected_kind, expected_review_id,
               expected_dispatch_id, expected_snapshot_epoch,
               expected_snapshot_fingerprint, expected_subject,
               expected_tool_use_id, expected_agent_id) -> policy.VerifiedWitness: ...
        # 1. strict-decode record; check kind/review/epoch/fingerprint/subject
        #    sha256(expected_subject) == record["subject_sha256"], plus
        #    expected_tool_use_id/expected_agent_id when not None.
        # 2. permits() on (kind, source, locator) - local kinds map to
        #    "hook-transcript", remote to "github-remote".
        # 3. For local kinds: open WitnessLog at record["source_locator"],
        #    verify_chain(), require record["record_positions"] entries exist,
        #    all carry record["transcript_range"]["session_id"], and the
        #    chain head through the last listed position equals
        #    record["chain_head_at_record"]. For remote kinds: policy-admit
        #    the locator and skip log checks (remote re-fetch is later).
        # 4. Every failure raises WitnessVerificationError with a specific code.
```

@dataclass(frozen=True)
class AuthoritySeed:
    kind: str        # one of model.AUTHORITY_KINDS
    locator: str     # canonical: "repo:<relpath>" | "gh:issue/<n>" |
                     # "gh:pr/<n>#body" | "gh:doc/<canonical-path>"
    declared_by: str # locator of the root/edge source that named it

@dataclass(frozen=True)
class AuthorityDiscoveryPolicy:
    policy_id: str           # "authority-discovery"
    version: str             # "1"
    document_sha256: str     # sha256 of the canonical policy document
    document: dict           # parsed policy document; enumerate_authorities reads it

def default_policy() -> AuthorityDiscoveryPolicy: ...
    # Loads references/authority-discovery-policy.v1.json relative to the
    # skill package; document_sha256 is the file's canonical JSON digest.

def resolve_policy(*, run_git, base_sha: str) -> AuthorityDiscoveryPolicy: ...
    # `git show <base_sha>:.agents/iterative-review/authority-policy.json`;
    # absent -> default_policy(); present -> parse + validate against the
    # policy schema (roots/edge grammar version 1) -> digest it.
    # NEVER reads the working tree / reviewed head. Self-qualification is
    # structurally impossible because the read path is base_sha-scoped.

def enumerate_authorities(
    *, policy: AuthorityDiscoveryPolicy,
    run_git, base_sha: str,
    pr_metadata: dict,          # canonical gh pr view projection (Task 4)
    load_text,                  # callable(locator) -> bytes|None for gh: locators
) -> tuple[list[AuthoritySeed], list[dict]]:
    """Returns (seeds, failures).

    Roots (v1 policy doc): every AGENTS.md and CLAUDE.md tracked at base_sha;
    .devin/rules/**; .agents/doctrine/**; the PR description; every issue in
    pr_metadata["linked_issues"]; every spec/plan/non-goal named by a root
    document's edges.

    Edge extraction: a document's edges come from (a) an
    `<!-- authority:edge <kind> <target> -->` marker or YAML front-matter
    `authority_edges:` list where present, and (b) structural rules in the
    policy doc (AGENTS.md governs .devin/rules/** and .agents/doctrine/**;
    a plan file's `**Spec:** <path>` header line -> implements edge).

    Traverse edges to a cycle-safe fixed point; canonicalize locators
    (POSIX rel paths, gh locators normalized); dedup on (kind, canonical
    locator). Ambiguous/unsupported/inaccessible/conflicting targets append
    to `failures` as {"locator", "reason"} records - the caller treats a
    non-empty failures list as a block, never a partial manifest.
    """

    def __init__(self, blocker_class: str, detail: str): ...

def enumerate_acquisition(
    *, run_git, run_gh, repo_root: Path, pr_number: int, out_dir: Path,
    scratch_dir: Path, epoch: int = 1,

    """Runs the witnessed enumeration; writes out_dir and returns a summary.

    Order and blocks (any failure -> AcquisitionError with blocker class):
      1. gh connector: `gh auth status` else "tool-blocked".
      2. PR identity: `gh pr view <n> --json ...` -> repository_id, pr_url,
         base_sha, head_sha; head must be remote-reachable else
         "snapshot-drift".
      3. Base resolution: `git merge-base <base_sha> <head_sha>` exactly one
         ancestor else "snapshot-drift"; `--is-shallow-repository` false.
      4. Worktree: `git status --porcelain` empty and `git rev-parse HEAD`
         == head_sha else "snapshot-drift" (uncommitted review input).
      5. git_object_format = `git rev-parse --show-object-format` (must be in
         model.GIT_OBJECT_FORMATS); tree_sha = `git rev-parse
         <head_sha>^{tree}`; diff_sha256 = sha256(`git diff <merge_base>
         <head_sha>` bytes); pr_metadata_sha256 over the content-bearing
         projection (title, body, labels, assignees, milestone,
         linked_issues); witness_policy_sha256 = the TranscriptWitnessPolicy
         sha256 computed for this review's transcript/witness roots (must
         equal the runtime verifier's policy digest - `_verify_witness`
         compares it against the snapshot field).
      6. resolve_policy + enumerate_authorities at base_sha; failures ->
         "authority-missing".
      7. Load every seed's bytes (repo: `git show base:path`; gh: pr body /
         issue body via gh api) -> loaded entries with sha256, or
         unavailable entries {failure_class, failure_sha256 over the
         captured error bytes}. Required-authority unavailability ->
         "authority-missing" block (repo-law, pr-description required;
         issue/document/plan/spec/non-goal/review-feedback entries degrade
         to unavailable records).
      8. enumerate_feedback -> review-feedback seeds + feedback bytes.
      9. Emit: out_dir/data.json {"snapshot": {...all SNAPSHOT fields sans
         fingerprint...}, "manifest_payload": <manifest payload>,
         "authorities": [...], "findings": <feedback findings>,
         "drift_reasons": [...]|null}; out_dir/evidence/<name> per byte blob

         "inputs": {repo_root, pr_number, base_sha, head_sha, epoch}}.
