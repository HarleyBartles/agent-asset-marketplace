# Rooms Source Partitioning v1

Use this skill for Rooms source-answering and evidence partitioning.

This skill owns the grounded-answering lane for Rooms. It decides how source, evidence, and report material are partitioned without flattening truth domains.

## Core rule

Separate what was seen, what was inferred, and what was only reported.

## Boundaries

- It does not own project doctrine.
- It does not own dispatch.
- It does not replace QA.
