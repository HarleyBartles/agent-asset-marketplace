# TPS Ingress v1

Use this skill when a report or review arrives and needs to be partitioned, routed, or returned through the lawful next step.

This skill is consumer-side TPS. It reads the TPS cover sheet, separates the claims, and forwards or returns the packet through the named route.

## Core rule

Read only enough to identify the source, the truth claim, and the correct return path.

## Boundaries

- It is not a generic validator.
- It is not a worker dispatcher.
- It does not invent new truth claims.
