# Adventures Bootstrap v1

Use this skill as the first read for Adventures work that needs a quick routing decision.

This skill routes to shared Adventures doctrine, the PSA/PIG stack, or the repo playbook. It does not mutate repo state or generate assets by itself.

## Core rule

Read the problem shape first, then route to the smallest Adventures surface that can own the work.

## Boundaries

- It does not replace project doctrine.
- It does not own visual production.
- It does not own repo publication.
