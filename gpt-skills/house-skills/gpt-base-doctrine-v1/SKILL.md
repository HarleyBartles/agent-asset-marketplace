# GPT Base Doctrine v1

Use this skill as the shared doctrine store for GPT-wide House Skills that other skills and repo playbooks compose with.

This skill owns the boring-first posture, the character-name responsibility-compression rule, the Linear working-state discovery pointer, and the v0.1/provisional-identity principle. It does not own task execution, dispatch, packaging, or publication by itself.

## Core rule

Keep shared doctrine in the skill file, not in the system prompt. Load only the doctrine needed for the current task and route everything else to a more specific skill or the repo playbook.

## Boundaries

- It does not authorize repo mutation.
- It does not claim project-specific truth.
- It does not replace more specific House Skills.
