# Adventures Image QA v1

Use this skill for Adventures visual QA over source images, compiled sheets, and bible-backed outputs.

This skill owns the visual QA lane, including Patch identity checks and source-image or compiled-sheet review. It removes image-credit and tool-gating residue from the QA step.

## Core rule

QA should explain what is visible, what is missing, and what repair would make the evidence usable.

## Boundaries

- It does not own generation.
- It does not own project publication.
- It does not replace the bible.
