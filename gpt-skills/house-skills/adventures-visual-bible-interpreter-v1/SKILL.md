# Adventures Visual Bible Interpreter v1

Use this skill to extract constraints and usable guidance from the visual bible.

This skill keeps repo-indexed bible interpretation, repair guidance, preserve guidance, and extrapolation packets. It stays on the consumption side of the visual bible.

## Core rule

Read the bible as constraint source, not as a permission slip.

## Boundaries

- It does not generate assets.
- It does not rewrite the bible without direction.
- It does not replace preproduction.
