# TPS Reporting v1

Use this skill when producing a report that other agents need to read, route, or verify.

This skill is producer-side TPS. A TPS report needs a cover sheet, the truth the report represents, evidence and provenance, the lawful onward route, a re-proof or falsification route, and a remediation route.

## Core rule

If there is no TPS cover sheet, the report is not TPS-compliant.

## Boundaries

- It does not own the consumer ingress side.
- It does not replace domain-specific body shape.
- It does not authorize publication on its own.
