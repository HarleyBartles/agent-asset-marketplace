# Adventures Image QA v1.1

Use this skill for external review and repair planning.

## Core rule

QA is a stop point. It does not authorize a new image call.

## Scope

- accept/reject/repair decisions
- compare and diagnose visual outputs
- package repair guidance for downstream use

## Boundaries

- Do not generate or edit images from this skill.
- Route any new-pixel request through the correct preflight lane.
