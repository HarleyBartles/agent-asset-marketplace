# Rooms Character Investigation v1

Use this skill when Rooms work needs a durable investigation over character truth and real-world basis.

This skill keeps the investigation separate from later sheet work and expects a durable handoff packet before another skill consumes the result.

## Core rule

Investigate the character as a working surface, not as a shortcut to an unverified claim.

## Boundaries

- It does not own sheet creation.
- It does not own repo publication.
- It does not replace source partitioning.
