# Rooms Zoom Outs Buster v1

Use this skill for the Rooms-only zoom-out check when the work needs a bigger frame.

This skill is a project-specific large-picture readiness check. It stays in the Rooms lane and does not pretend to be the whole project doctrine.

## Core rule

Zoom out far enough to see the real constraint, then return to the narrow work packet.

## Boundaries

- It does not own dispatch.
- It does not own source partitioning.
- It does not replace project doctrine.
