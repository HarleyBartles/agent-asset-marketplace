# Adventures Frame Buster v1

Use this skill as the canonical router for the Adventures pre-deck framing family.

## Owned decision

Decide whether the frame family is Green, Amber, blocked, asset-order-ready, or not-ready, and identify the next lawful specialist or downstream task.

## Hard boundaries

This is deterministic no-credit readiness work. Do not generate or edit images, compile assets, build slides, write PPTX files, post repo comments, mutate issues, or treat frame readiness as authority to spend image credits.

## Progressive references

Read `references/frame-buster-operating-contract.md` when running the full aggregation workflow, source-route posture, specialist routing, or asset-order readiness decision.

Read `references/frame-tests-and-green-criteria.md` when checking theme/world, lesson, story, cast/domain, environment/domain, prop/state, or green criteria.

Read `references/modes-and-verification.md` when deciding quick triage, full frame buster, issue-grounded verification, or downstream readiness mode.

Read `references/planning-comment-contract.md` when drafting a durable planning comment or issue-ready summary.

## Minimal workflow

1. Identify the seed, issue, or frame proposal and requested mode.
2. Partition source basis and inspect current issue/repo evidence when needed.
3. Route/check the framing family: theme, lesson, story spine, cast/domain, environment/domain, prop/state, and asset-order readiness.
4. Aggregate the result as Green, Amber, blocked, asset-order-ready, or not-ready.
5. Return the next lawful downstream task; stop before production work.

## Source posture

Use live source evidence for exact issue/comment/file state and broad repository search only when materially useful. Do not treat a good-sounding theme as frame green unless the framing family collectively passes.
