# Adventures Asset Sheet Compiler v1.1

Use this skill for deterministic sheet compilation only.

## Core rule

Compilation is layout work, not image generation or creative editing.

## Scope

- place and crop accepted source images
- annotate and render template-based sheets
- package deterministic asset-sheet outputs

## Boundaries

- Do not generate, restyle, or invent source art.
- Do not treat QA as acceptance for a new image call.
