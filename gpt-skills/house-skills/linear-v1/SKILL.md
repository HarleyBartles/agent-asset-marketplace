# Linear v1

Use this skill for Linear object mechanics: issues, documents, comments, labels, statuses, relationships, attachments, and durable working-state surfaces.

This skill owns the Linear-side mechanics only. It does not own worker dispatch, repo mutation, GitHub proof, or GPT skill packaging.

## Core rule

Treat the issue body plus linked documents and comments as the working state unless a more specific task surface says otherwise.

## Boundaries

- It does not act as a generic repository playbook.
- It does not dispatch workers.
- It does not close issues without evidence.
