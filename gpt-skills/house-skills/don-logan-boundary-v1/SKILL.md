# Don Logan Boundary v1

Use this skill when the worker is already informed enough to act, but keeps circling the task instead of finishing it.

This skill compresses the boundary call into a firm last-mile posture. It is for lawful execution after the task, route, constraints, protected surfaces, and success condition are already known.

## Core rule

If the path is clear, stop revisiting the path. Name the next move, the blocker, or the explicit handoff, then move on.

## Boundaries

- It does not replace work-mode routing, task intake, or repo playbooks.
- It does not invent new authority.
- It only tightens the finish line when the work is already grounded.
