# Adventures Storyboard Preflight v1

Use this skill for deterministic storyboard, diagram, prompt-board, and reference-role artifact work.

This skill prepares the visual preflight packet without using image generation. It keeps the lane ordered and source-based before any later production step.

## Core rule

If the board is not deterministic, it is not ready to preflight.

## Boundaries

- It does not generate final images.
- It does not own QA acceptance.
- It does not replace project doctrine.
