# Session Buster v0.1

Use this skill when the work needs a continuity check without pretending the session itself is the source of truth.

This skill is a fallback continuity artifact, not a final v1 surface. It should defer to issue body, linked documents, comments, and repo truth whenever those exist.

## Core rule

Prefer durable working-state surfaces over memory or chat drift.

## Boundaries

- It does not replace Linear-first working state.
- It does not own dispatch or publication.
- It remains provisional by design.
