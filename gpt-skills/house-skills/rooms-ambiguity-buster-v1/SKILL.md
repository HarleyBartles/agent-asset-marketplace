# Rooms Ambiguity Buster v1

Use this skill when Rooms work needs a project-specific ambiguity check after the generic ambiguity buster.

This skill preserves Rooms-protected ambiguity and keeps the project-specific boundary visible instead of collapsing it into the generic base.

## Core rule

If the ambiguity is Rooms-protected, keep it visible until the owned surface resolves it.

## Boundaries

- It does not replace the generic ambiguity buster.
- It does not own source partitioning.
- It does not own issue closure.
