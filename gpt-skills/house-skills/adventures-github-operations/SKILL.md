# Adventures Github Operations

Use this skill when Adventures work needs repo proof, branch hygiene, PR status, or issue-linked evidence.

## Owned decision

Handle the GitHub proof surface, verify the current repo state, and route the request to the correct follow-up skill or worker.

## Hard boundaries

This skill does not generate images, edit creative assets, or decide visual content.

Treat source discovery, issue handling, repo mutation, PR publication, and visual work as separate lanes.

## Minimal workflow

1. Confirm the request actually needs GitHub proof or repo state.
2. Check the current branch, PR, or issue surface.
3. Gather only the evidence needed for the next lawful step.
4. Stop before trying to do downstream creative or production work.
