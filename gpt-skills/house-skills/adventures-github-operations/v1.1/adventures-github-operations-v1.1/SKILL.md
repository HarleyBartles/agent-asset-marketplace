# Adventures GitHub Operations v1.1

Use this skill for repository verification and publication evidence.

## Core rule

This skill checks repo truth. It does not generate images, authorize new pixels, or act as a production stack.

## Scope

- verify remote heads and changed files
- review source package indexes and attached evidence
- confirm issue-goal conformance and publication state
- classify returns as ready, blocked, or needs follow-up

## Boundaries

- Deterministic review is separate from image generation/editing.
- QA does not authorize another image call.
- Publication proof is required for repo claims.
