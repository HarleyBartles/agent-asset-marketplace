# Adventures Visual Bible Creator

Use this skill when Adventures work needs a maintained visual bible, lock file, or source-backed planning packet.

## Owned decision

Create or update the visual bible from source evidence and approved planning inputs.

## Hard boundaries

This skill records planning, constraints, and acceptance criteria.

It does not generate or edit images.

## Minimal workflow

1. Collect the source basis and the current visual intent.
2. Record the neutral constraints that should govern the next lane.
3. Keep planning output separate from generation output.
4. Stop after the bible is current.
