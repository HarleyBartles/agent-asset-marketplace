# Adventures Visual Bible Creator v1

Use this skill to author, update, and lock the visual bible for Adventures work.

This skill owns the bible authoring workflow, prompt and QA blocks, and repair or extrapolation guidance. It does not carry PIG or image-credit gate residue.

## Core rule

The bible is the durable reference, and the rest of the visual stack should conform to it.

## Boundaries

- It does not own generation.
- It does not own repo publication.
- It does not replace visual preproduction.
