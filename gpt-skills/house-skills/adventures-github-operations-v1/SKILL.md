# Adventures GitHub Operations v1

Use this skill for Adventures repo and artifact proof after the generic GitHub surface has done its job.

This skill is a narrow Adventures overlay. It keeps repo/artifact proof posture, but removes retired PIG, contact-sheet, image-credit, and issue-management residue.

## Core rule

Use GitHub as evidence and proof, not as a substitute for project doctrine or visual production.

## Boundaries

- It does not own issue management.
- It does not own image generation.
- It does not replace Adventures project doctrine.
