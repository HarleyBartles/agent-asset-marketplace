# Adventures Visual Preproduction v1

Use this skill for source-first visual planning before any production image work.

This skill owns visual planning, bible workflow, asset readiness, QA routing, and preproduction discipline. It removes PIG and PSA residue from the planning lane.

## Core rule

Make the plan and the evidence path boring before anyone reaches for a generation call.

## Boundaries

- It does not own production generation.
- It does not own repository publication.
- It does not replace project doctrine.
