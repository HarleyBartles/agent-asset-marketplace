# Adventures Visual Preproduction v1

Use this skill after frame greenlight and before deck or PPTX production when Harley asks ordinary GPT/project workflow to prepare Adventures visual assets, visual direction, prompt boards, source-image readiness, QA routing, PIG production-packet readiness, or asset-sheet readiness. This is the GPT/project visual-preproduction control plane, not the image-generation gate and not PIG execution doctrine.

## Owned decision

Decide the current visual-preproduction lane and next safe stage: deterministic planning, source discovery, visual bible work, GPT-side storyboard/prompt-board preparation, PSA pre-vis handoff, PSA-return review, image-preflight handoff, image-QA handoff, asset-sheet compilation handoff, PIG handoff, or blocked readiness.

## Hard boundaries

Do not spend ordinary GPT image-generation credits from this skill. Deterministic preproduction exists to conserve scarce image capacity and reduce failed production calls. A plan, accepted prompt board, QA failure, active workflow, or `continue` does not authorize ordinary GPT generation. Before any GPT-side visible image mutation, route through Adventures visual intent and image preflight, then stop after one generated or edited candidate. When the next actor is PSA, emit a paste-ready deterministic pre-vis packet and treat returned boards as planning/control artifacts only. When the next actor is PIG, emit a bounded production packet or readiness report, optionally carrying reviewed PSA boards as grounding inputs; do not treat this skill as PSA rendering, PIG generation, PIG self-QA, or PIG regeneration authority.

Do not put bootstrap text, session busters, repo rollups, issue comments, skill package state, or other operator context into visual prompts, asset sheets, labels, or deck visuals unless Harley explicitly asks for a status artifact.


## Actor boundary

This is a GPT/project-side visual-preproduction control plane. It is PSA-aware in the sense that it can route deterministic board work to PSA and review PSA returns. It is PIG-aware only in the sense that it can prepare bounded inputs for PIG. It must not teach PIG to avoid generation inside a valid PIG production job, and it must not claim PIG self-QA, regeneration, or final acceptance authority.

## Progressive references

Read `references/preproduction-operating-contract.md` when you need the full lane workflow, required inputs, readiness report shape, prompt governance detail, or failure handling.

Route to adjacent skills instead of duplicating their work:

- Use Adventures image preflight before any ordinary GPT-side source-image generation/edit request.
- Use the PSA stack for assigned deterministic pre-vis/storyboard/prompt-board jobs; this skill may prepare and review the handoff but does not render as PSA.
- Use the PIG production stack for assigned PIG image-production jobs; this skill may prepare the handoff but does not execute it.
- Use Adventures image QA for candidate or compiled-sheet accept/edit/regenerate/block decisions.
- Use Adventures storyboard preflight for lightweight GPT-side storyboard/prompt-board construction or PSA handoff packet preparation.
- Use Adventures asset sheet compiler for deterministic template compile/package work.

## Minimal workflow

1. Classify the request as deterministic preproduction, PSA pre-vis handoff/review, candidate QA, image-preflight, asset-sheet compile, PIG handoff, or blocked.
2. If source/repo evidence matters, inspect the relevant source route before claiming readiness.
3. Keep deterministic work no-credit.
4. Produce the next preproduction packet or route to the owning adjacent skill.
5. Stop at review points instead of laundering readiness into image generation.
