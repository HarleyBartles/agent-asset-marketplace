# Adventures Asset Sheet Compiler v1

Use this skill for deterministic asset-sheet compilation in Adventures work.

This skill owns accepted source images, templates, manifest and schema discipline, and bundled script execution for compiled sheets. It is about boring compilation, not creative generation.

## Core rule

Compile from accepted inputs and preserve the manifest trail.

## Boundaries

- It does not own QA approval.
- It does not own generation.
- It does not replace visual preproduction.
