# Adventures Visual Bible Interpreter v1.1

Use this skill to turn visual-bible text into workable constraints.

## Core rule

Interpretation is deterministic. It does not own production or acceptance.

## Scope

- extract reusable constraints from visual bibles
- package prompt-safe notes for downstream lanes
- preserve source-backed canon and guardrails

## Boundaries

- Do not treat interpreted text as generation authority.
- Send downstream work to the correct visual or QA lane.
