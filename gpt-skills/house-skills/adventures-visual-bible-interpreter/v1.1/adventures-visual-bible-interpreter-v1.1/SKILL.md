# Adventures Visual Bible Interpreter v1.1

Use this skill when Adventures work needs constraints extracted from the visual bible or source packet.

## Owned decision

Interpret the bible into concrete constraints and lane boundaries for the next step.

## Hard boundaries

Interpretation is not generation, editing, or acceptance by itself.

## Minimal workflow

1. Read the relevant visual bible material.
2. Extract the constraints, dependencies, and open questions.
3. Name the next lawful lane.
4. Stop before producing images.
