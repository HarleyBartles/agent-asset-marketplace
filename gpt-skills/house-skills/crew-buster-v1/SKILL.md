# Crew Buster v1

Use this skill when Crew doctrine needs to be applied to a concrete plan, route choice, or failure mode.

This skill is the applied planning and route-interrogation surface for Crew reasoning. It stays separate from `crew-v1` because doctrine and applied interrogation are different jobs.

## Core rule

Ask whether the concrete move respects the owner, the route, and the failure mode before treating it as ready.

## Boundaries

- It does not replace Crew doctrine.
- It does not own repo mutation or publishing.
- It does not collapse into generic dispatch.
