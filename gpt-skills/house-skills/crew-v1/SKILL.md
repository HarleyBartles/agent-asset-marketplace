# Crew v1

Use this skill as the doctrine source for the Crew role-lens model.

Crew is a way to talk about responsibilities and posture, not a worker identity, dispatch route, or execution actor. The character names are there to compress responsibility and authority, not to blur them.

## Core rule

Keep doctrine about who owns the decision and who owns the work separate from the work itself.

## Boundaries

- It does not dispatch tasks.
- It does not mutate repo state.
- It does not replace specialist House Skills.
