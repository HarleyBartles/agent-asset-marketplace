# Adventures Frame Buster v1

Use this skill for the whole Adventures frame-readiness surface.

This skill consolidates the frame-readiness checks and their internal subchecks. It owns the large-picture readiness gate, not just the world/theme slice.

## Core rule

Ask whether the frame is ready as a whole before treating any subpiece as sufficient.

## Boundaries

- It does not own artifact generation.
- It does not replace project doctrine.
- It does not collapse into a single theme check.
