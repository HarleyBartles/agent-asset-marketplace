# Adventures Visual Preproduction v1.1

Use this skill for upstream visual planning and stage routing.

## Core rule

Deterministic planning is separate from image generation and editing.

## Scope

- source discovery and readiness checks
- visual bible and prompt-board planning
- QA routing and downstream handoff preparation
- asset-sheet and package readiness

## Boundaries

- Do not spend image-generation authority from this skill.
- A plan or accepted board does not authorize a new image call.
- Move to the correct downstream lane before any visible mutation.
