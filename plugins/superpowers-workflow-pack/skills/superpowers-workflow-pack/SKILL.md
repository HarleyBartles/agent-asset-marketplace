# Superpowers Workflow Pack

This is a local MARK-2 projection for the private Codex marketplace. It is not a mirror of upstream Superpowers skill text.

## Use This To Do

Install this plugin to help Codex run a boring, auditable engineering loop:

1. Confirm the task source and repository identity.
2. Preserve provenance and licensing notes for any upstream asset that informs the work.
3. Separate reusable asset identity from the installable plugin projection.
4. Plan before broad implementation.
5. Prefer small, reviewable edits.
6. Verify with the strongest available checks.
7. Finish with branch, commit, changed-files, validation, and publish-readiness evidence.

## Guardrails

- Available upstream does not mean safe to mirror.
- Safe to list does not mean safe to bundle.
- Metadata-only/reference-only records are valid outcomes for unclear or intentionally unbundled sources.
- Future tool, framework, hook, runtime, or localization support should be tracked as horizon metadata instead of treated as excluded.
- If third-party content is copied in a future projection, carry license notices and update provenance before making it installable.

## Quality Bar

A retained or projected asset should have:

- provenance metadata;
- license posture;
- quality/readiness metadata;
- localization/translation posture;
- validation coverage; and
- a concise audit artifact.
