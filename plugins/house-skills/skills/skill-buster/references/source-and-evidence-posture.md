# Source and Evidence Posture

Use this reference only when skill-update queue work actually depends on repository evidence, connector availability, external package evidence, source-route claims, or a failed source route.

Do not enter source-route reasoning merely because a connector, file, source, or tool namespace is present.

When source evidence is needed, select from the capabilities exposed in the current runtime. Prefer exact live repository operations for known issues, comments, files, commits, pull requests, compares, and authorized mutations. Prefer indexed repository discovery for broad stale-pattern sweeps, unknown-path searches, or multi-file corpus reads when that capability is available.

Do not treat a search miss, unbound indexed discovery route, or one route failure as proof that a repository, file, issue, or skill does not exist. State the route used and what remains unverified.
