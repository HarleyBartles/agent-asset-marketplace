# Canon green paths

Canon Buster can go green through more than one route.

## Modify the item

Use when established canon is stronger and the item can be adjusted without losing its purpose.

## Modify canon

Use when the item is stronger or newer Harley or Rooms intent should move the world state. This requires lawful Rooms routing before claiming canon changed.

## Modify both

Use when the item reveals a better shape but both the item and the existing canon surface need revision.

## Preserve boundary

Use when the item is valid in another layer: archive evidence, report, manuscript unreliability, character belief, narrator limitation, working theory, or conversation candidate.

## Preserve ambiguity

Use when resolving the conflict would flatten intended uncertainty.

## Defer pending evidence

Use when relevant source surfaces are unavailable or the evidence chain is insufficient.
