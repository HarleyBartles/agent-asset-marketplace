# Repo-worker-base pressure scenarios

These scenarios define the RED baseline for the repository-worker composition
contract. They are checked in with Task 1 and are intentionally not executable
skill changes.

- `repo-backed-superpowers-lane.md` covers mandatory base-skill and local-guide
  pairing before a downstream Superpowers lane.
- `worktree-resolution.md` covers portable worktree and scratch-path discovery.
