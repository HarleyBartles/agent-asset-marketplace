# Completed Artifact Custody

Use the [completed artifact custody standard](references/standard.md) only when a repository explicitly adopts or asks to assess `completed-artifact-custody`. Installing this skill or another workflow capability does not adopt the standard. Determine semantic completion from the artifact's full scope and repository evidence, whether or not a marker exists.
